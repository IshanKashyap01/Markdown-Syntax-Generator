# Markdown Syntax Generator

A Java library for generating Markdown syntax.

Markdown is simple until you need to generate the awkward stuff. Images, links,
tables, and other syntax-heavy constructs quickly become annoying to build
manually with string concatenation.

Markdown Syntax Generator provides a simple API for generating valid Markdown
without having to remember or manually assemble the syntax yourself.

*Note*: Compatible with Java 11 and later

## Features

Generates markdown syntax for:

1. Images

2. Links

3. Tables

## Maven Coordinates

```xml
<groupId>io.github.ishankashyap01</groupId>
<artifactId>markdown-syntax-generator</artifactId>
<version>1.0.0</version>
```
